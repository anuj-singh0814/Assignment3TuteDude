# Assignment3TuteDude

This repository contains two Python scripts:

Factorial Calculation: A recursive function to compute the factorial of a given number.

Mathematical Operations: A program that takes a user-input number and calculates its:

Square root

Natural logarithm (base *e*)

Sine (in radians)

Requirements
Python 3.x

math module (included in Python's standard library)

Usage
**1. Factorial Calculation**
The function factorial(n) computes the factorial of a number using recursion.

**2. Mathematical Operations**
The program prompts the user to enter a number and then calculates:

Square root (math.sqrt)

Natural logarithm (math.log)

Sine in radians (math.sin)
